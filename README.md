# Problem Pulse

Problem Pulse is a research engine that discovers recurring user problems from public online discussions.

The goal is to help developers and founders identify validated opportunities by analysing public conversations, grouping similar problems, and generating structured insights.

## Features

* Collect public discussions from supported platforms
* Extract pain points using AI
* Cluster similar problems
* Rank opportunities by frequency and severity
* Generate concise research reports

## Supported sources

* Reddit (planned)
* GitHub Issues (planned)
* Hacker News (planned)
* Product Hunt (planned)

## Status

🚧 Early prototype.

This project is currently under active development.
